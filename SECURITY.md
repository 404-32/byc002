# Security policy

MoonCompat reads `.mbti` text supplied by users and does not execute checked
projects or package code.

Please report parser crashes, denial-of-service inputs, or unexpected file
writes privately to the repository owner through GitHub. Include:

- MoonBit toolchain version;
- input `.mbti` file;
- command line;
- expected and observed behavior.

Do not include secrets or proprietary source code in a public issue.
